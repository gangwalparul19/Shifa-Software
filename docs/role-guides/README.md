# Shifa OMS — Role Guides

Short, task-focused quick-start guides. Open the one that matches your job. A brand-new user should be
able to read their guide once and start working. For the complete reference, see
[`../USER-MANUAL.md`](../USER-MANUAL.md).

| Your role | What you do | Guide |
|---|---|---|
| **Admin** | Run the whole business: approvals, config, fulfilment oversight, finance | [admin.md](admin.md) |
| **Salesperson** | Take orders, manage leads and your customers | [salesperson.md](salesperson.md) |
| **Team Lead** | Oversee your team, punch orders for them, track performance | [team-lead.md](team-lead.md) |
| **Packing User** | Pack, label, hand over and dispatch parcels | [packing-user.md](packing-user.md) |
| **Payment Verifier** | Check that payments are genuine before fulfilment | [payment-verifier.md](payment-verifier.md) |
| **Accountant** | Reconcile money, COD, expenses, P&L, ledger | [accountant.md](accountant.md) |
| **CA (Chartered Accountant)** | GST dashboards, returns filing, accounting (read-only) | [ca.md](ca.md) |

**Common to everyone:**
- Sign in with your username (salespeople: your mobile number) and password.
- All times are shown in **IST**.
- The menu only shows what your role can use (left sidebar on desktop, ☰ drawer + 4 bottom tabs on mobile).
- Press **Ctrl+K** for global search / quick actions.
- Open **My Profile** from the account menu to request detail changes (an admin approves them).
